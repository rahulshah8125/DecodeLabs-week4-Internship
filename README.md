# 🏪 Superstore Sales & Profit Analysis

## 📌 Project Overview

This project analyzes retail sales data from a Superstore business to identify revenue drivers, profitability patterns, and regional performance trends. The project combines data analysis, visualization, and predictive modeling.

---

## 🎯 Objectives

* Analyze sales and profit trends.
* Identify top-performing categories.
* Understand regional performance.
* Predict profit using machine learning.

---

## 📊 Dataset Features

* Order Details
* Sales
* Profit
* Quantity
* Discount
* Category
* Sub-Category
* Customer Segment
* Region
* State

---

## 🛠️ Tasks Performed

### 1️⃣ Dataset Understanding

* Data exploration.
* Feature identification.
* Dataset structure analysis.

### 2️⃣ Data Cleaning

* Missing value handling.
* Duplicate removal.
* Data quality improvement.

### 3️⃣ Exploratory Data Analysis

* Sales Analysis
* Profit Analysis
* Category Performance
* Regional Trends

### 4️⃣ Data Visualization

* Sales by Region
* Profit by Category
* Sales Distribution
* Category Analysis

### 5️⃣ Predictive Modeling

* Profit Prediction using Linear Regression
* Model Performance Evaluation

---

## 📈 Key Insights

* Technology products generated high revenue.
* Regional sales performance varied significantly.
* Discounts impacted profitability.
* Profitability patterns could be predicted using sales-related features.
